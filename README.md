# 교실도움

교사를 위한 브라우저 기반 AI 프롬프트 준비 도구입니다. 학년, 교과, 수업 주제와 필요한 도움을 입력하면 수업 준비에 활용할 프롬프트를 만들어 줍니다.

## 사용 방법

`index.html`을 브라우저에서 열고 수업 정보를 입력한 뒤 **맞춤 프롬프트 만들기**를 선택하세요. 생성된 프롬프트를 복사해 사용 중인 AI 서비스에 붙여 넣으면 됩니다. 별도 설치나 API 키가 필요하지 않습니다.

입력한 정보는 이 페이지에서 처리되며 저장하거나 AI 서비스로 전송하지 않습니다. 외부 AI에 프롬프트를 붙여 넣을 때는 학생의 이름, 연락처, 성적 등 개인을 식별할 수 있는 정보를 포함하지 말고 해당 서비스의 개인정보 정책을 확인하세요. AI가 만든 자료는 수업에 사용하기 전에 교사가 검토해야 합니다.

## 확인

정적 HTML 파일이라 별도의 빌드나 테스트 명령은 없습니다. `index.html`을 브라우저에서 열어 프롬프트 생성과 복사 기능을 확인할 수 있습니다.
