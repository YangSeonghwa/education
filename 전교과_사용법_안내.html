전교과 수업설계 통합지침 기본형 v1.0

국어·영어·수학·과학·사회 전 교과 공용 · NotebookLM 소스 1개 + 맞춤설정 1회

0. 이 도구는 무엇인가요?

교과서·지도서 기반으로 시나리오 → 슬라이드 → 학습지를 단계별로 만드는 지침입니다. 과학 전용 용어(미토콘드리아, 전자 등)가 제거된 공용 기본형으로 시작하고, 사용 후 /지침개선으로 내 교과 맞춤 지침(v1.1…)으로 진화합니다.

⚠️ 과학 특화본(v1.5)은 과학 수업에만 사용. 다른 교과는 반드시 전교과 기본형 v1.0을 사용하세요.

1. 준비물 (3개)

  1. 해당 교과 교과서 PDF
  2. 해당 교과 지도서 PDF
  3. 기본형 지침 1개: 00_최우선지침_전교과_수업설계통합지침_기본형_v1.0.md

2. 설치 3단계 (5분)

① 새 노트북 만들기

NotebookLM → 새 노트북 → 교과서 + 지도서 업로드

② 소스에 지침 업로드

소스 추가 → 전교과 기본형 v1.0 파일 1개만. 파일명 앞 00_최우선지침_ 유지.

③ 맞춤설정 1회 입력

채팅창 > Configure Chat > Custom > 아래 복사 > Longer > Save

너는 전교과 수업설계 보조. 교과서/지도서 근거 우선, 없으면 "현재 자료에서 확인되지 않음".
수업단위는 교과서 p.xx~yy로만 표시, 차시는 페이지로 풀어씀.
모든 산출물(시나리오/슬라이드/학습지)은 [질문→A/B/C 3종 아웃라인 표 제시 후 정지→선택 확정 후 최종출력] 순서. 단일 아웃라인 금지, 선택 전 최종출력 금지.
1·2단계 끝은 반드시 "원하시는 번호를 말씀해주세요.(예: B형)"로 끝내고 대기.
한 번에 산출물 1개만. 근거 없는 비유·단정 금지.
첫 대화면 교과·학년과 본수업 페이지 범위를 1줄로 묻고 시작.

맞춤설정은 교과가 바뀌어도 수정 불필요. 버전업 때도 그대로 둡니다.

3. 수업 만들기 순서

Step 1. 시나리오
/시나리오 → 질문 답 → A/B/C 선택 → /시나리오-아웃라인-확정 → /시나리오-확정
Step 2. 슬라이드
/슬라이드 → 질문 답 → A/B/C 선택 → /슬라이드-확정
Step 3. 학습지
/학습지 → 질문 답 → A/B/C 선택 → /학습지-확정
Step 4. 진화
/지침개선 → 피드백표+변경점+전문 출력 → 새 파일 교체 → 교과 맞춤 v1.1

4. 규칙 3개

  • 3종 선택 강제: 항상 A/B/C 표. 1개만 나오면 “3종으로 다시”.
  • 확정 전 출력 금지: 선택 전 최종본 금지.
  • 1회 1산출물: 한 번에 1개만 요구.

5. FAQ

Q. 교과별로 따로 사야 하나요?
A. 아닙니다. 기본형 1개로 전 교과 시작, /지침개선 후 국어v1.1·영어v1.1 등으로 분기 저장하면 됩니다.

Q. 예시가 과학처럼 나와요.
A. 과학 특화본이 섞인 경우. 전교과 기본형 1개만 남기고 삭제 후 “처음부터” 입력.
